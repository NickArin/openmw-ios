# openmw-ios

Personal iOS build of [OpenMW](https://openmw.org) 0.51.0 — build scripts and CI only.
No game data, no mods, no assets in this repo (OpenMW itself is GPL-3.0; Morrowind data files are yours to supply on-device).

Target: iPhone 17 Pro, sideloaded via SideStore (unsigned IPA, signed on-device with a personal Apple ID).

Build state and results: see the auto-filed **CI run** issues in this repo.
Plan: `BUILD_PLAN.md`.
